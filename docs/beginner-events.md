# 首页小白活动推荐

运营后台的「资源管理」支持在新建、编辑赛事活动时勾选「首页小白活动推荐」，也可在列表的「小白推荐」列直接开关。首页「管理小白活动推荐」进入已推荐列表；取消「仅看小白推荐」可查看全部资源。此开关独立于「精选」。

仅已发布、未超过截止日期的赛事活动会显示；截止当天按 Asia/Shanghai 时区计算并继续展示。没有截止日期的活动不会自动过期，仍可手动取消推荐。列表沿用资源时间顺序，每页最多 12 条。

「卡片配色」作用于整张赛事卡片，支持莓粉、紫藤、松绿、天青、金杏、素白；深色主题使用对应深色背景。其他资源卡片不受影响。

部署前应用 `20261029094245_beginner_event_recommendations.sql`。该迁移新增默认关闭的布尔字段及赛事类型约束，并将推荐设置纳入现有管理员编辑字段保护。保留现有成员登录要求和资源 RLS 策略。活动选择属于运营数据，不在迁移或前端中硬编码。
