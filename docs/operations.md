# 翎语运营指南

管理员登录后，从页脚进入「运营后台」，或访问 `/admin/`。网站账号与 Supabase 控制台账号分开管理，管理员身份由数据库分配，不能通过修改个人资料获得。

## 资源与报名

在「资源管理」新增或编辑赛事活动、实习、工具等内容，填写标题、组织、说明、地点、截止时间及官方链接。赛事可上传官方封面图，用户可从详情转发到社区发布组队帖。

站内报名默认关闭。仅在由平台运营者主持、需要平台收集报名的活动中开启。外部比赛或实习应引导用户自行访问官方链接。

保存草稿后仅运营者及有权人员可见；发布后登录成员可浏览。下架可改回草稿。删除前确认其关联影响，数据库会按迁移中的外键及业务规则清理相关数据。

## 发布课程

1. 在「课程管理」新增课程，填写名称、一句话介绍、课程介绍、授课人署名、标签与封面配色。
2. 切换到「02 课时与课件」，为每节填写标题与预计分钟；可以输入文字讲义，也可直接使用附件作为内容。
3. 点击「上传 HTML / 课件 / ZIP」。每份最多 20MB，每节最多 8 份；课时可调整先后顺序。
4. 在「03 预览与发布」检查学生看到的目录、内容、互动、阅读和下载，再保存草稿或发布。

HTML 请使用内嵌样式、脚本和图片的单文件 `.html` / `.htm`，多个章节分别放入对应课时。PDF 支持翻页、缩放和本页文字；PPTX 为静态幻灯片预览；旧版 PPT、Word 与 ZIP 下载后使用。视频上传未实现。

移除附件会解除课程关联，未关联的存储对象不会自动对成员开放；文件清理需通过受控的存储管理流程。

## 社区与个人空间

成员可发布动态、评论、转发赛事并寻找队友。只有作者可以编辑自己的资料、帖子与评论；点击他人头像进入其个人名片，不能修改他人信息。

## 内测邀请

进入「内测邀请」查看批次、使用状态和有效期。已有批次不因打开或刷新后台而自动增加。确有需要时再手动生成，妥善保存当次返回的完整邀请码并按需导出；缩略标识不能用于注册。

每个码限一个新账号。输入内测码注册后，还需完成邮箱确认；已有账号直接登录，不需要重复消耗内测码。邀请码无法提升权限。

## 用户与申请

「用户列表」仅向管理员展示注册昵称与邮箱。个人信息导出不要提交到源码仓库。

「申请审核」处理已开启的站内报名和加入申请。通知展示审核结果，并按账号保存已读状态。

## 代码发布

先运行 `pnpm typecheck`、`pnpm test` 和 `pnpm build`，再将 `out/` 内容部署到现有腾讯云项目。源码提交到 GitHub 不会自动发布官网，也不会更改或迁移 Supabase 用户与文件。

生产配置始终保存在本机 `.env.local` 或部署服务的环境设置中；SMTP、数据库口令等由服务商控制台管理。修改前端连接配置后需要重新构建，仓库仅保存空白 `.env.example`。
